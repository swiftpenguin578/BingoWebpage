## Changes

- Added an `entry={id}` read on the Audit page. It uses the same filtered, hidden-event-inclusive query as the list, so missing, filtered-out or unavailable entries render “This entry isn't available” instead of throwing or returning an error page.
- Added entry links from the list and rendered a selected entry through the existing `_AuditEntry` and `AuditPresenter` path. Sensitive details remain withheld and hidden-event rows remain readable to an authorized Admin.
- Replaced the typed Event ID field with a server-populated event select. It includes hidden events and labels them as hidden.
- Computed date bounds before composing the EF predicate. `To=9999-12-31` and other out-of-range values now produce field validation feedback rather than an exception during query parameter evaluation.
- Kept the existing exact-action/area filters, Copenhagen calendar-day conversion, stable ordering and database paging unchanged.
