# AU24 F1 remediation evidence

## Scope

This checkpoint implements the AU24 F1 remediation from `review-notes/21-codex-brief-b1-b2-remediation.md`, item 1, based on the findings in `review-notes/20b-b1-au22-au24-review.md`. The brief is the user-authorized assignment forwarded to this lane. The confirmed destination-ID method is now the only public ownership-transfer entry point.

## Changes

- Removed the public username-only transfer overload.
- Removed the public destination-ID overload that accepted no username confirmation.
- Required a nonblank confirmation and compared it with the selected account's normalized public username before checking the password or mutating either account.
- Updated existing transfer, stale-session, reset-policy, operator-recovery and race tests to use the confirmed destination-ID call.
- Added coverage for a missing confirmation, a random wrong name, another existing account's name, case-insensitive confirmation, and persisted state after rejected attempts.
- Added an HTTP form rejection for a missing confirmation and reloaded PostgreSQL state to prove that roles and ownership-transfer audit rows are unchanged.
