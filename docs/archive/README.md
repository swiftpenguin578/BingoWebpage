# Historical archive

This directory preserves historical evidence from the repository. Archive material is non-authoritative and may be stale or contradictory. It is excluded from ordinary inventories, searches, planning, implementation, and review.

Search the archive only for an explicitly named provenance, migration, or manual-evidence investigation. Current active documents and current user decisions win. If a valid decision or rule is recovered, promote it into an active source of truth before implementation; do not implement directly from an archive entry.

The archive is additive and recoverable. Historical documents are archived rather than deleted after their durable material has been promoted and the replacement has been verified. The archive index records the provenance and current destination for each entry.

See [`INDEX.md`](INDEX.md) for the entry schema and the archived handoff inventory. The active handoff is [`CURRENT_STATUS.md`](../../CURRENT_STATUS.md), and the current remaining-delivery authority is [`DELIVERY_PLAN.md`](../../DELIVERY_PLAN.md).
